できること

専用のGroup Nullを1つの操作点にして、タイムライン上のレイヤーをまとめます。専用Effectは画像処理をせず、Groupの識別とLayer Countの保持に専念します。

G

タイムライン基準のGroup

Group Nullより下方向にあるレイヤーを、Layer Countで指定した数だけ候補にします。Group Null自身は数えません。Layer Countは0からComp全体のLayer数まで動かせます。

↳

既存Parentを守る

対象内の子Layerは元のParent関係を保ち、Root LayerだけをGroup Nullへ接続します。外部Parent付きのLayerや循環ParentになるLayerは、自動改変せずスキップします。

fx

通常Effectを自動同期

Group Nullに追加した通常のAfter Effects Effectを、Group対象へ順次コピーします。コピー側の値はExpressionで元Effectを追従し、Child固有のEffectは残します。

↶

Apply / UngroupをUndo可能に

Apply前のParentとGroup Markerを退避し、予期せぬ失敗時は復元を試みます。Ungroupでは記録したParentを戻し、Group Controlが管理したコピーだけを掃除します。

仕組み

レイヤーを単純に全部Parentするのではなく、対象範囲の中からRootだけを接続します。これで元の親子構造を保ったまま、Group NullのTransformを使えます。

導入

配布物はPanelとネイティブEffectの2つです。After Effectsを終了してから配置し、起動し直してください。既存のPanelを開いたままファイルだけ差し替えた場合は、古いコードが動き続けます。

Windows

PanelはJSXBIN、ネイティブEffectはAEXとして配置します。

  1. After Effectsを終了する。
  2. PanelをScriptUI Panelsへ置く。Support Files\Scripts\ScriptUI Panels\NGS_GroupControl.jsxbin
  3. Effectを専用フォルダへ置く。Support Files\Plug-ins\NGS Group Control\GroupControl.aex
  4. After Effectsを起動し、WindowメニューからPanelを開く。

macOS

Universal bundleに含まれるPluginを、インストール済みのAEへ配置します。

  1. After Effectsを終了する。
  2. NGS_GroupControl_macos-universal.zipを展開する。
  3. Pluginを専用フォルダへ置く。/Applications/Adobe After Effects 2024/Plug-ins/NGS Group Control/
  4. After Effectsを起動し、Panelを開く。AE 2024以外はフォルダ名を読み替える。
Panelが空になる場合

GroupControl.jsxをそのままJSXBIN化せず、先にincludeを展開したBundleを作ります。変換後のファイルに#includeが残っていないことも確認してください。

使い方

Panelの操作は少しだけです。作業中のCompを開き、Group Nullを選択した状態でLayer CountとEffectを調整します。

01 / Create

Groupを作る

対象にしたいLayerを選んでCreate Group。Group Nullが作られ、選択中のLayer数がLayer Countの初期値になります。何も選ばなければ0です。

02 / Shape

範囲を決める

Group Nullを選択し、− / ＋でLayer Countを調整します。変更後はその場でApplyされ、現在のタイムライン位置から対象が決まります。

03 / Drive

まとめて動かす

Group NullのPosition、Scale、Rotationなどを操作します。Panel起動中にGroup Nullへ通常Effectを追加すると、対象Layerへ順次同期されます。

Ungroupするとき

Group Nullを選択してUngroup。記録されたParentを戻し、管理用のMarkerとEffectコピーを削除してGroup Nullを取り除きます。直接子Layerの記録が足りない場合は、安全のため削除を中止します。

注意点

v1は「既存の構造を勝手に壊さない」ことを優先しています。自動で補正しないものを先に知っておくと、Status Textの意味を判断しやすくなります。

Group Nullにキーがある

Position、Scale、Rotation、3D Orientationなどにキーが1つでもあると、Apply全体を開始しません。キーの補正やベイクは行いません。

外部Parentがある

対象外のLayerをParentに持つRootは、既存Parentを守るためGroup Nullへ接続しません。候補数には含まれ、後続Layerで補充されません。

Rootに有効なExpressionがある

影響Transformに有効なExpressionがあるRootはスキップします。既存Expressionの書き換えや、ワールドTransformの補正は行いません。

Opacity / Anchor Point

v1ではGroup Opacityを実装していません。Group NullのAnchor Pointも自動計算せず、AE標準Nullの値を使用します。

ビルドと検証

PanelはExtendScript互換のES3、EffectはAfter Effects SDKを使います。SDKはAdobeのライセンス対象なので、macOS用SDKを公開リポジトリへ置かないでください。

困ったとき

まずPanelを閉じて、ファイルを差し替えたあとに開き直します。Panelの監視は古いコードを自動で更新しないため、再読み込みが重要です。

Panelが空、またはボタンが表示されない

GroupControl.jsxを直接変換せず、node tools/build_group_control_panel_bundle.jsでincludeを展開してからJSXBIN化します。生成Bundleに#includeが残っていないこと、var GroupControlPanel = buildUI(this);があることを確認してください。差し替え後は古いPanelを閉じ、After Effectsを再起動して開き直します。

Deep Glow 2などでパラメータ名が見つからない

Effectのコピーによって表示名が変わる場合があるため、同期式は走査時の数値Property indexを使って参照します。修正版へ差し替えたあとPanelを開き直し、古い監視処理がExpressionを書き戻さない状態にしてから同期を待ちます。

Effect追加時に処理が止まる、または反映が遅い

同期はLayer、Property、Effect追加を分割し、通常監視は200ms、処理継続中は10ms間隔で次の区切りを予約します。重いEffectの単一追加そのものは短縮できません。Effect名、対象Layer数、追加時か値変更時かを記録し、検証手順に沿って模擬ホストとAE実機を分けて確認してください。

一部のLayerだけが動かない

Status Textの「外部Parentスキップ」「Expression付きRootスキップ」「循環Parentスキップ」を確認します。これらは既存構造を守るための仕様です。対象範囲を変えた場合は、Group Nullの位置とLayer Countを確認してからApplyします。
